YUCOM V1.2.0（通用串口测试工具）
===============================

YUCOM 用于检查计算机、工控机、主板和外接设备上的串口是否能够正常发送、
接收。Windows版使用内嵌WebView2独立窗口，麒麟原生版使用GTK独立窗口；两者均不调用
外部浏览器，也不依赖Minicom、ServiceLink、Python或特定串口芯片。

界面与交互为 YUCOM 独立实现，仅采用通用串口测试工具常见的功能分区思路；
本项目不使用参考软件的商标、图标、源代码或原始视觉资源。此说明不构成法律意见，
如需对外商用，仍应由相关法务进行商标和外观审查。

主要功能：

  1. 自动识别常见板载、USB、PCIe和多串口扩展设备；
  2. 支持 /dev/serial/by-id 稳定设备名称；
  3. 300～921600波特率、5～8数据位、1/2停止位、奇偶校验和流控；
  4. 文本/HEX收发、结束符、暂停显示、自动滚动、字节计数；
  5. 标准文本测试帧；
  6. 512字节原始数据硬件回环自检；
  7. 定时发送和Modem信号显示；
  8. 不保存配置、接收内容或测试日志；
  9. Windows版和麒麟原生版使用独立窗口；旧Linux网页版只允许本机访问。

支持系统和架构：

  Linux桌面系统，包括银河麒麟、Ubuntu、Debian等
  ARM64 / aarch64
  x86_64 / amd64
  Windows 10/11 x86_64 / amd64
  Windows ARM64

串口设备驱动必须已经由系统正确加载；YUCOM用于测试串口，不负责安装硬件驱动。

麒麟原生版构建（首次需要管理员准备开发依赖）：

  sudo apt-get install build-essential pkg-config libgtk-3-dev
  bash "scripts/构建麒麟原生版.sh"
  bash "scripts/启动YUCOM.sh"

安装开发依赖会修改系统软件包，属于管理员操作；YUCOM脚本本身不会自动执行sudo。
原生窗口运行时只需要系统已有GTK3运行库，不需要浏览器。

Linux快速启动：

  cd 解压后的目录
  bash "启动YUCOM.sh"

麒麟开发板也可以直接执行“一键运行YUCOM.sh”：如果原生程序已经编译，脚本会直接启动；
如果尚未编译，离线测试设备会直接提示缺少程序，不会联网、不运行apt-get，也不会修改系统。
请在联网开发机上使用 `YUCOM_INSTALL_DEPS=1 bash scripts/一键运行YUCOM.sh` 安装开发依赖并编译，
再运行 `bash scripts/打包麒麟离线运行包.sh` 收集原生程序和运行库，生成压缩包，通过U盘复制到测试设备。客户运行机只需
解压并运行“一键运行YUCOM.sh”，不需要 Go、gcc、pkg-config 或 GTK3 开发包。

离线运行包会把 GTK 相关的非核心动态库放在 `runtime/lib`，启动时仅对 YUCOM 进程设置
`LD_LIBRARY_PATH`。系统核心库（glibc、动态加载器等）不打包、不覆盖；因此离线运行包应在
与测试设备相同的麒麟版本和CPU架构上制作。

如果测试机还缺少系统级 GTK 运行包，安装入口会自动调用包内的
`安装麒麟离线依赖.sh`，从 `offline-debs` 使用 `dpkg` 安装，然后继续启动；不会调用网络。
联网开发机可先执行 `bash scripts/准备麒麟离线依赖.sh` 下载这些 `.deb`，再执行离线打包脚本。

如果不想分步操作，在同版本、同架构的联网麒麟开发机只执行：

  bash scripts/一键制作麒麟离线包.sh

脚本会自动补齐开发依赖、编译、下载离线运行依赖并生成最终 `.tar.gz`。最终包内还包含
`YUCOM.desktop`；文件管理器允许启动该文件时可以双击运行，否则执行
`bash 一键运行YUCOM.sh`。两种入口都会使用同一套离线自动安装逻辑。

启动脚本会自动判断CPU架构，优先运行麒麟原生窗口；若目录中没有原生二进制，
才回退到旧版本机网页。所有串口操作由本地YUCOM进程完成，数据不会发送到互联网
或局域网。

Windows快速启动：

  双击 YUCOM-Windows-amd64.exe

Windows版启动后直接显示独立的WebView2窗口，不调用Edge或其他外部浏览器。Windows
10/11通常已包含WebView2 Runtime；如果系统提示无法加载WebView2，请安装或修复微软
WebView2 Runtime后重试。界面只连接YUCOM进程在127.0.0.1随机端口建立的本机服务，
不会访问互联网或局域网。串口名称显示为COM1、COM2、COM9等。关闭YUCOM窗口即可
退出。窗口四边和四角均可用鼠标拖动调整大小；程序不安装服务、不写入注册表、不保存
配置或串口数据，也不会弹出控制台窗口。
