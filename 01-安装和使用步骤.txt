YUCOM 安装和使用步骤
====================

一、软件定位
------------

YUCOM用于测试设备上的串口能否正常收发，不绑定特定主板、串口芯片或PCB。
它不替换串口驱动，也不修改Minicom和系统已有串口配置。

软件无需安装：解压后运行即可。测试完成后可直接删除整个目录。

二、运行前只读检查（无风险）
----------------------------

  uname -m
  ls -l /dev/ttyS* /dev/ttyAMA* /dev/ttyUSB* /dev/ttyACM* 2>/dev/null
  find /dev/serial/by-id -maxdepth 1 -type l -print 2>/dev/null

第一条检查CPU架构，后两条只列出串口，不修改系统。

三、启动（低风险）
------------------

  bash "启动YUCOM.sh"

交付给客户的麒麟离线包只需执行一次：

  bash "一键运行YUCOM.sh"

该命令会优先启动原生窗口；若检测到包内运行库仍不足，会自动调用同目录的
`安装麒麟离线依赖.sh` 和 `offline-debs`，然后继续启动。不会访问网络、不安装
Go/gcc、不改动系统原有串口。若需要sudo，系统只会要求本机管理员输入密码。

在同版本、同架构的联网麒麟开发机制作交付包也只需执行一次：

  bash "scripts/一键制作麒麟离线包.sh"

该制作命令可能通过APT安装编译工具，属于中等风险，只在开发机执行。最终生成的
`.tar.gz` 包含原生程序、进程私有运行库、离线 `.deb`、操作说明和 `YUCOM.desktop`。
测试设备解压后可以执行上述一键命令；若桌面文件已被麒麟信任，也可双击
`YUCOM.desktop`。首次双击若系统提示“允许启动”，这是桌面安全机制，不是联网安装。

启动脚本自动选择ARM64或x86_64程序，优先运行麒麟原生窗口，只给当前二进制增加
用户执行权限；不需要sudo、不安装软件包、不设置开机启动。

原生版不启动HTTP服务、不调用浏览器；所有串口操作在本地窗口内完成。

如果目录中没有原生二进制，脚本才会回退到旧网页版：该模式只监听127.0.0.1的
随机本机端口并打开默认浏览器，其他电脑无法访问。

麒麟原生版首次构建（中等风险，仅开发机执行）
------------------------------------------------

管理员先安装GTK3开发依赖：

  sudo apt-get install build-essential pkg-config libgtk-3-dev

上述命令会修改系统软件包，只应在编译机上执行；交付给客户的运行机不需要执行，
只需具备GTK3运行库。然后执行：

  bash "scripts/构建麒麟原生版.sh"
  bash "启动YUCOM.sh"

Windows启动（低风险）
---------------------

Windows 10/11直接双击 YUCOM-Windows-amd64.exe。Windows ARM设备使用
YUCOM-Windows-arm64.exe。程序会直接打开内嵌WebView2的独立窗口，不调用外部浏览器，
也不会弹出额外的控制台窗口。Windows 10/11通常已包含WebView2 Runtime；如果启动时
提示无法加载WebView2，请安装或修复微软WebView2 Runtime。界面只连接127.0.0.1上的
YUCOM本机服务，不访问互联网或局域网。程序不需要管理员权限，不安装驱动、不注册
服务、不修改注册表。把鼠标移到窗口四边或四角，出现缩放光标后可按住左键拖动调整大小。

四、打开串口（低风险、可恢复）
--------------------------------

1. 点击串口号右侧“↻”扫描设备。Linux显示/dev/tty...，Windows显示COM1、COM2等。
2. 根据设备管理记录或硬件资料选择正确串口。
3. 设置与对端完全相同的波特率、数据位、停止位、校验和流控。
4. 点击“打开串口”。

打开后只会临时独占当前选中的端口，其他串口不受影响；关闭即可释放。

如提示Permission denied，执行以下只读检查：

  id
  ls -l /dev/对应串口

不要对全部串口执行chmod 777。修改dialout用户组属于永久权限变更和中等风险，
必须得到设备负责人授权；YUCOM不会自动修改。

五、基本收发测试
----------------

方法A：连接一台已知正常的外部串口设备，在发送区输入测试内容，点击单次发送；
观察对端是否完整收到，再让对端回复，检查YUCOM接收区。

方法B：点击“标准测试帧”，YUCOM发送带时间标识的英文、数字测试内容；对端应
完整接收。标准测试帧只证明发送动作完成，必须结合对端实际接收结果判断。

方法C：正确连接硬件回环线后点击“硬件回环自检”。YUCOM发送512字节原始数据，
只有收到完全一致的序列才显示通过。

六、回环自检风险（必须阅读）
----------------------------

回环接线前先关闭串口并给设备断电。必须根据接口资料确认电气标准：

  普通UART/TTL：TX连接RX，但两端电压必须匹配。
  RS232：同一端口TXD连接RXD。
  RS422：TX+连接RX+，TX-连接RX-。
  RS485：两线半双工通常不能用单端口自回环作唯一结论。

严禁把TTL、RS232、RS422、RS485不同电平直接短接。接口不明时不要使用回环，
改用已知正常的外部设备双向测试。

RS485驱动可能在发送时关闭本机接收器，因此回环未通过不一定表示端口损坏；
应使用第二个RS485端口或标准USB-RS485设备进行双向测试。

七、HEX和定时发送
-----------------

HEX发送示例：

  55 AA 01 02 03 0D 0A

“HEX显示”按原始字节显示接收数据。文本乱码时先用HEX确认是否有数据，再检查
双方串口参数和文本编码。

定时发送会持续向外部设备写数据，属于中等风险。确认目标和内容后再启用，最小
间隔50ms；关闭串口或发送失败时自动停止。

八、退出
--------

1. 停止定时发送。
2. 点击“关闭串口”。
3. Windows和麒麟原生版直接关闭YUCOM窗口；Linux网页版点击页面右上角“退出程序”。
4. 改接线前给设备断电。

YUCOM不保存配置和串口内容，不注册服务。删除解压目录即可移除软件。
